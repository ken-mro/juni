利用規約

制定日: 2026年9月6日

この利用規約(以下「本規約」)は、ken-mro(以下「運営者」)が提供するタイピングゲーム「FLICK IMPACT」(https://flick-impact.com で提供するウェブサイトおよびこれに付随する機能。以下「本サービス」)の利用条件を定めるものです。本サービスを利用する方(以下「ユーザー」)は、本規約に同意したうえで本サービスを利用するものとします。

第1条(適用)

  1. 本規約は、ユーザーと運営者との間の本サービスの利用に関わる一切の関係に適用されます。
  2. 本サービスにおける個人情報の取扱いは、別に定めるプライバシーポリシーによります。プライバシーポリシーは本規約の一部を構成します。
  3. ユーザーは、本サービスにアクセスし、またはプレイした時点で本規約に同意したものとみなされます。本規約に同意いただけない場合は、本サービスを利用できません。

第2条(本サービスの内容)

  1. 本サービスは、フリック入力で落下することばの隕石を破壊するブラウザ向けのタイピングゲームです。
  2. 本サービスは無料で提供されます。利用にあたって通信料などの費用が発生する場合は、ユーザーの負担とします。
  3. 本サービスは、ユーザーの端末のブラウザ内(localStorage)にプレイの記録と設定を保存します。これらはユーザーの端末内にとどまり、ログインしなくても利用できます。
  4. ユーザーは、任意で Google アカウントによりログインすることで、記録と設定を運営者のサーバーに保存し、別の端末に引き継ぐこと(以下「クラウド同期」)ができます。

第3条(Google アカウントによるログイン)

  1. クラウド同期を利用するには、Google アカウントによるログインが必要です。ログインは Google が提供する認証の仕組みを通じて行われ、Google アカウント自体の利用については Google の定める規約が適用されます。
  2. 運営者がログインに際して取得する情報は、Google アカウントの識別子と表示名のみです。メールアドレスその他の情報は取得しません。詳細はプライバシーポリシーに定めます。
  3. ユーザーは、自己の責任において Google アカウントを管理するものとし、第三者に利用させてはなりません。ログイン済みの端末を第三者に使用させたことにより生じた損害について、運営者は責任を負いません。
  4. ユーザーはいつでもログアウトできます。ログアウトしても、端末内に保存された記録と設定は消えません。

第4条(プレイデータの取扱い)

  1. クラウド同期で運営者のサーバーに保存されるのは、レベルごとのベスト記録(クリアタイム、最大コンボ、撃破数、行別・方向別の正答率、達成日時)、設定(入力ガイド・ヒント・効果音・BGM・開始レベル・隠しステージのベスト友好度)およびその更新時刻です。
  2. 複数の端末で本サービスを利用した場合、記録はレベルごとにタイムの短いほう、設定は更新が新しいほうを採用して統合されます。統合により一部のデータが置き換わることがあります。
  3. 運営者は、サーバー上のプレイデータが消失・破損しないよう合理的な努力をしますが、その保存を保証するものではありません。運営者は、通信障害、システムの障害、サービスの変更・終了その他の事由によりプレイデータが消失・破損した場合でも、その復旧や補償の義務を負いません。
  4. ユーザーは、サーバーに保存されたプレイデータの削除を運営者に求めることができます。方法はプライバシーポリシーに定めます。

第5条(禁止事項)

ユーザーは、本サービスの利用にあたり、次の行為をしてはなりません。

  1. 法令または公序良俗に違反する行為
  2. 他のユーザーの Google アカウントを使用し、または他人になりすまして本サービスを利用する行為
  3. 本サービスの API に対し、改ざんしたプレイデータや本サービスの想定しない形式のデータを送信する行為、その他不正な記録を登録しようとする行為
  4. 本サービスのサーバーやネットワークに過度の負荷をかける行為、または本サービスの運営を妨害する行為
  5. 本サービスの脆弱性を悪用し、またはサーバーその他の設備に不正にアクセスする行為
  6. 本サービスに含まれるコンテンツを、本規約で許諾された範囲を超えて複製、改変、頒布、販売する行為
